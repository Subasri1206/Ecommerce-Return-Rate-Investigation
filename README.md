# 📦 E-Commerce Return Rate Investigation

## 🎯 1. Problem Statement
Product returns are a major challenge in e-commerce businesses because they increase operational costs and reduce profitability. This project analyzes customer return behavior and identifies the factors contributing to product returns.

## 📊 2. Dataset Description
The dataset contains e-commerce order information including product details, customer information, delivery performance, ratings, discounts, and return status.

### Dataset Summary
- Total Orders: 5000
- Total Returned Products: 2500
- Return Percentage: 50.0%
- Average Delivery Duration: 3.35 Days
- Average Product Price: 145.73
- Average Customer Rating: 3.96
- Total Features: 22

## 📈 3. Statistical Methods
- Data Cleaning and Preprocessing
- Descriptive Statistics
- Mean, Median and Standard Deviation
- Quartile Analysis
- Correlation Analysis
- Outlier Detection using IQR Method
- Hypothesis Testing (T-Test)
- Data Visualization

## 🔍 4. Return Findings
- Overall return rate is 50%.
- Delivery delays influence product returns.
- Customer ratings impact return behavior.
- Product pricing affects return decisions.
- Certain product categories show higher return rates.

## 📉 5. Visual Insights
The following visualizations were created:
- Category vs Return Rate
- Price vs Return
- Delivery Days vs Return
- Discount vs Return
- Customer Rating vs Return
- Correlation Heatmap

## 💡 6. Recommendations
1. Improve delivery efficiency.
2. Monitor high-return categories.
3. Strengthen product quality checks.
4. Improve product descriptions.
5. Review discount strategies.
